# The 26 rules

Each rule has a vulnerable and a patched fixture contract and a sandbox exploit that works on the first and fails on the second. The scanner reports patterns in source, so a finding is a reason to look, not a proof (see [Limits](limits.md)). The [README](../README.md) carries the one-line version of this table; `scanner/src/rules/mod.rs` has a test that every rule has a row there.
