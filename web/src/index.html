About this demo

The key in this page is public on purpose: it can only call flip on a demo contract and has a small gas allowance. Everything here is NEAR testnet. The registry's auditor is an account I control, so this shows what each check keys on, not that a verdict is right. A timer I run resets the demo to the vulnerable build after 10 idle minutes on the fixed one (no swap in that time).

The left card is a plain allowlist by account id. It is not a model of any particular wallet or agent.

About this simulation

This scripted agent is shown holding a key that can spend. My testnet agent holds only function-call keys, which can attach no deposit; the guard check is the same.

It plays what happens when an agent obeys a poisoned page. The guard's registry check runs on the live reads above; the guard's spending policy is set by the agent's owner and has no default, so this script assumes one that allows this contract and 0.5 NEAR per call. A real language model was the agent in recorded testnet runs: it followed the injected page in 8 of 10, and the guard refused all 16 injected calls before signing. Read the recorded runs.

            What this asks GitHub for
            
Asks api.github.com for the file list and raw.githubusercontent.com for each .rs and Cargo.toml file, without signing in. api.github.com allows 60 requests an hour per connection and a scan uses 2, so about 30 scans an hour. Large repositories are cut off at a stated limit.

          

        

      


      

        

        

        

        

      

    

  


  

    

      
What this is and is not

    

    

      

        What the scan is
        
A set of syntactic rules that read the shape of your Rust code, not what it does when it runs. Each rule is backed by a vulnerable contract it flags, a patched one it leaves alone, and a sandbox test that exploits the first and fails on the second. Every finding links to that proof. One rule (PF022) also reads the build settings in Cargo.toml, so it can only report on a GitHub scan: pasted source is a single file with no manifest, and that rule stays silent on it.

      

      

        What it is not
        
Not an audit. It can miss bugs and it does not follow every code path. A clean result means no known rule fired, not that the contract is safe.

      

      

        Where your code goes
        
Pasted and bundled source is scanned inside this page by WebAssembly. The GitHub tab is the only thing that makes requests, and only to GitHub, for the repository you name.
